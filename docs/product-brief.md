# Forksview Product Brief

## Product

Forksview is a personal, native, Mac-only Markdown viewer/editor and learning project. It operates on ordinary individual `.md` and `.markdown` files, with one document per window. Rendered reading mode is the default; the pencil control and `⌘E` toggle editing.

Forksview requires standard native document operations: New, Open, Open Recent, Save, Save As, Duplicate, Rename, Move, drag-and-drop, and opening files from Finder.

## v1 experience

The main window has three panes:

- Left: History sidebar.
- Center: reading/editing canvas.
- Right: outline/bookmark inspector.

The app preserves a useful reading or editing position across mode changes and safely handles files modified externally.

## Visual direction

The [visual target](reference/forksview-ui-target.png) is inspiration for layout and mood, not an app asset.

## v1 non-goals

Folders/workspaces, tabs, cloud sync, accounts, collaboration, telemetry, updater, plugins, publishing, export formats, App Store distribution, and cross-platform support are out of scope for v1.
